# Spatial Document v1 — Converged Design Spec

**Status:** design **ratified by Seth 2026-08-12** — bounded to **design shape + implementation scope**. This approval does **NOT** authorize activation, a runtime grant, deployment, or worn-headset execution. Those remain behind a **separate build/device/arming gate.**
**Provenance:** three independent design drafts (Claude, muse, Codex) on `spec/spatial-doc-v1`, converged. Concretizes [`2026-08-08_quest-agent-client.md`](./2026-08-08_quest-agent-client.md) §3–5 + [`2026-08-12_spatial-doc-research-landscape.md`](./2026-08-12_spatial-doc-research-landscape.md).

## 1. The v1 slice
One **snapshot-only, bounded spatial scene** over passthrough: a small hierarchy of panels/text, quads, line strips, and **at least one real URI-free GLB mesh**. Reuses the existing session epoch, short-lived presentation lease, focus/presence narrowing, monotonic document revision, exact-byte hash, and post-display bounds ack. Adds: render-profile negotiation, a content-addressed resource plane, hostile-input admission, atomic scene swap, and a Vulkan projection renderer.

**Presentation only — zero new perception authority.** No passthrough pixels, scene/depth, anchors, hands, gaze, or body. `xrLocateViews` is needed to render a projection layer, but display-driving views **never cross JNI/log/wire/serialization** — they stay inside the native frame loop. The raw-visual four-fact/bystander floor does not apply. Focus/presence remain narrowing-only.

## 2. Authority (ledger 1) — new, disabled-first, no silent migration
- New exact capability **`interaction.quest.surface.document.present`**, **disabled-first**, constraints = `{components, resource_classes, spaces}`. It uses the existing presentation-lease machinery, but **existing `panel.present` grants do NOT migrate** and cannot authorize GLB/image resources. This is presentation-authority expansion (not perception).
- Old `PANEL_SNAPSHOT` (schema 1/2) paths stay unchanged. The four-leaf voice manifest is untouched; a future manifest schema may replace its `panel` leaf with `presentation` as an **explicit later migration** — not v1. v1's spatial slice uses its own exact LEASE.
- mTLS + HELLO grant nothing. Every snapshot/resource frame carries the lease; authority is **rechecked before commit and before display**; expiry/revoke/disconnect/focus/presence-loss narrows synchronously.

## 3. Renderability (ledger 2) — negotiated profile, never authority
- HELLO advertises exact **profiles**, not optimistic flags: `soma.quest3.spatial-document.v1` with `schema_versions`, `components` (`panel.v1, text.v1, primitive.quad.v1, primitive.line.v1, mesh.glb.uri-free.v1, material.unlit.v1, material.solid.v1`), `resource_formats` (`text.utf8.v1, image.rgba8.v1, glyph-atlas.v1, mesh.glb.v1`), and `limits` (document_bytes ~24 KiB, resource_ingress_bytes, resident_bytes, entities, hierarchy_depth, draws, vertices, triangles, line_segments, texture_dimension/pixels). **Numbers are Threshold-measured knobs, not protocol truths.**
- HELLO_ACK selects one exact profile id/schema, repeats effective limits, supplies a **SHA-256 over the exact UTF-8 bytes of the selected profile object** (exact-byte wrapper, as the document uses — no semantic canonicalization, so implementations cannot disagree on the bytes); documents name that id+hash. Required-unsupported components **reject** the snapshot (X3D fail-closed profile principle); optional-unsupported degrade only via an explicit declared fallback, recorded in the receipt. **Profile support grants no authority.**
- **Join point:** commit requires **one live authority decision AND one successful render admission**; the receipt references both without merging their meaning. The renderability ledger can refuse/reduce work but can never create/broaden a grant, infer consent, or keep content alive after authority closes.

## 4. Message types (extend the existing line-framed v1 envelope + lease-binding rule)
Add leased types: **`SPATIAL_SNAPSHOT`**, **`RESOURCE_CHUNK`** (single type; snapshot descriptor is the offer), **`SPATIAL_ADMISSION_RECEIPT`**, **`SPATIAL_DISPLAY_RECEIPT`**, **`SPATIAL_ROLLBACK_RECEIPT`**. `lease_ref` required for all; HELLO/suspend/teardown remain un-leased narrowing-only. Old `PANEL_SNAPSHOT` untouched; new path uses new types + exact profile so an old client **fails negotiation** instead of misparsing.

**`SPATIAL_SNAPSHOT.payload`** keeps v1a's exact-byte wrapper: `{document_encoding:"base64-json-utf8", document_byte_length, document_sha256, document_b64}`; hash covers exact received UTF-8 bytes (no semantic canonicalization). Decoded document has exact fields: `schema, schema_version:1, profile_id, profile_sha256, document_id, revision, session_epoch, lease_ref, ttl_ms, required_components, optional_components, declared_cost, entities[], resources[], presentation[], dynamics[], semantics[]`. **`dynamics` MUST be empty in v1.** Unknown top-level/component fields **reject** (never ignore).

## 5. The five sets — v1 subset
- **entities:** `{id, parent_id|null(+space:"view"|"local"), local_transform{translation_m, rotation_xyzw(unit quat±tol), scale(positive,bounded)}, declared_local_bounds, visibility, presentation_ids[]}`. Topologically ordered, acyclic, within depth. **Client never trusts declared bounds:** it derives primitive bounds + decodes mesh positions, transforms+unions with checked arithmetic; **actual geometry escaping the declared AABB beyond tolerance → reject**; conservative overdeclaration may shrink in the receipt. Hidden entities stay admitted/resident, produce no draws, still counted honestly.
- **resources (content-addressed, immutable):** `{id, kind, format, sha256, byte_length, required, fallback_presentation_id|null}`. Resolve by document-local id then exact digest — **no URI/path/hostname/resolver/data-URI/filesystem fields; the headset never fetches.** Formats: `text.utf8.v1` (strict UTF-8, bounded, no NUL, not stored in provenance); `image.rgba8.v1` (tightly-packed 8-bit RGBA; w/h/row-bytes in an exact descriptor, checked-arithmetic to byte length — **no PNG/JPEG decoder in v1**); `glyph-atlas.v1` (bounded UTF-8 JSON metrics closing over one `image.rgba8.v1` digest, ≤256 glyphs; the 5x7 shell font may be a preloaded resource by its bytes' digest); `mesh.glb.v1` (§7).
- **presentation:** each record has `id, type`, only that type's fields. `panel.v1` (w/h, radius, background material_ref, optional border; text is a child `text.v1` entity — not a hidden widget runtime); `text.v1` (text_resource_ref, glyph_resource_ref, material_ref, size, max_width, alignment, bounded line count; **no markup/HTML/scripts/bidi-controls/downloadable-font**); `primitive.quad.v1` (w/h, material_ref, optional image_resource_ref); `primitive.line.v1` (bounded inline finite local-space points, width, join=bevel, material_ref); `mesh.glb.uri-free.v1` (mesh_resource_ref); `material.solid.v1` (linear RGBA, opaque); `material.unlit.v1` (the document material for meshes/quads — **not** the glTF `KHR_materials_unlit` name on the wire; that extension is cited as prior art only). Materials map **only to precompiled SPIR-V variants** — no shader source/binary/graph/custom-pipeline/blend/target.
- **dynamics:** empty in v1.
- **semantics (non-interactive):** accessibility/degradation metadata only — `required_for_meaning:bool`, integer `degrade_priority`, accessible `label`, optional `fallback_presentation_id`. **No action bindings or sensor sources.** Interaction/hit-test deferred.

## 6. Resource transfer plane
Soma sends bytes on the mTLS content plane via **`RESOURCE_CHUNK`** `{resource_sha256, kind, format, byte_length (= the §5 descriptor's total), chunk_index, chunk_count, byte_offset, bytes_b64}` — field names match the §5 descriptor (`resource_sha256`/`kind`/`byte_length`, not `hash`/`class`/`total_len`); `bytes_b64` is **canonical base64 of ≤24 KiB raw bytes** per chunk (the 24 KiB cap is on raw bytes, before base64 expansion). Sent before/after the snapshot. **Framing caps checked before allocation.** Overlap, gaps, length/digest changes, excess outstanding resources, or quota overflow **abort that resource**. Bytes publish into a **session-local immutable cache only after the assembled SHA-256 matches exactly**. A newer snapshot may cancel an uncommitted candidate; lease expiry/revoke/disconnect clears assembly + session cache. **Cross-session caching deferred; safest v1 clears cache on reconnect and retransfers.** Missing required resource → bounded pending (not a partial scene) until preparation TTL; missing/invalid optional → its declared fallback (which may not introduce anything outside the snapshot closure).

## 7. URI-free GLB subset (geometry-only)
GLB 2.0 as **asset substrate, not endpoint authority.** Magic/version 2; exactly one JSON chunk + **exactly one BIN chunk** (required — positions+indices always need it); checked lengths/alignment; under the resource cap. Exactly one default scene + one identity root node + one mesh — **document entities own the live hierarchy/transforms** (no duplicate graph semantics). Allowed objects: `asset, scene(s), nodes, meshes, accessors, bufferViews, one embedded buffers`. **Reject:** any `uri`, all extensions, extras, animations, skins, morph targets, cameras, lights, images, textures, samplers, sparse accessors, compression, external buffers, **and `materials`** — geometry-only; appearance comes solely from the document `material.unlit.v1`. Primitive mode TRIANGLES; **POSITION required float VEC3, COLOR_0 optional; NORMAL/TEXCOORD not in v1**; indices required U16/U32 SCALAR; buffer views tightly packed/aligned/in-bounds. **Geometry-only — no material/normal/UV/texture in the GLB;** the document `material.unlit.v1` supplies appearance. Independently scan every decoded position/color/index (reject NaN/Inf, out-of-range index, degenerate/over-cap); **recompute AABB + counts from bytes** (accessor min/max + sender cost are hints only); custom allocation budget in the parser; fuzz framing/JSON/accessors/upload. A pinned, attributable parser (e.g. `cgltf`) may do structural parsing wrapped by Soma caps/allocator + the independent scan — **a successful third-party parse is not admission.**

## 8. Nine-stage admission → atomic commit
1. **Frame** — validate outer length/base64/exact-fields/doc-length/resource-totals/counts/integer-arithmetic/UTF-8/session-flow **before** allocating proportional memory.
2. **Schema/graph** — exact schema/profile/component types; ids/refs; topological acyclic hierarchy within depth; finite transforms; empty dynamics; no forbidden semantics/extensions.
3. **Closure/integrity** — enumerate full resource/fallback closure; require session-cache bytes at exact length+hash; **no URI/path resolution**; pending bounded+cancellable.
4. **Decode limits** — parse RGBA/glyph/GLB **off the OpenXR frame thread** with allocation/output quotas; decoding creates no live GPU objects and does not mutate the active scene.
5. **Recompute** — derive topology, decoded/resident bytes, draw/vertex/triangle/line/texture counts, local/world AABBs, placement/comfort facts. **Underdeclared cost or escaping bounds → reject.**
6. **Static admission** — compare recomputed facts vs selected profile + hard device caps + health class + deterministic comfort limits. Hard-invalid/hard-cap → reject. Budget pressure chooses only declared fallbacks / optional omissions in a **stable order**, recorded.
7. **Prepare + atomic commit** — build an immutable candidate scene, stage Vulkan resources, wait for upload fences, then recheck epoch/live-lease/doc-id/revision/hash/focus/presence/profile/TTL; at **one frame boundary atomically swap** the active scene generation; prior coherent scene is the rollback target; advance `last_committed_revision` only here. Same revision+same hash = idempotent; same revision+different hash = reject.
8. **Runtime** — meter frame CPU/GPU/resident/device-loss/thermal; cancel preparation on narrowing; the governor applies **only declared deterministic degradation**; on first-frame/device failure revert to prior authorized generation or the local offline shell — **never a half-uploaded graph**.
9. **Receipts** — semantic admission/display/rollback receipts, **separate from transport ACKs**; provenance stores metadata (ids/hashes/counts/reasons) **never bodies/text/mesh-bytes/view-poses**.
Preparation is single-candidate per document in v1; a newer valid snapshot cancels the older uncommitted candidate; a rejected snapshot never destroys the live scene. Revocation/focus-loss is different — it synchronously removes eligibility + the old scene, retaining only the client-owned suspended shell.

## 9. Receipts (distinct channels)
- **`SPATIAL_ADMISSION_RECEIPT`** (after reject, atomic commit, **or while a candidate is pending**): epoch, lease_ref, doc id/revision/hash, profile id/hash, outcome (`committed|degraded_committed|pending|rejected`), committed generation, recomputed cost, scene + per-entity actual AABBs, selected fallbacks/omissions + reason codes, missing digests for pending. **Does not claim display.**
- **`SPATIAL_DISPLAY_RECEIPT`** (successor to `ACTUAL_BOUNDS_ACK`): only after `xrEndFrame` succeeds with that generation — `displayed:true`, same revision/hash/generation, actual bounds, applied degradation ledger. Evidence of client submission, **not** human perception/acceptance.
- **`SPATIAL_ROLLBACK_RECEIPT`**: failed generation, restored generation or local-shell, bounded reason (`device_lost|first_frame_failed|runtime_budget`). **Lease close is NOT a rollback reason** — an expired/revoked lease cannot authorize a leased frame; Soma already closed it, and the revocation/focus-loss path (§8) synchronously removes eligibility + the scene, leaving the client-owned suspended shell. No post-close receipt is required or authorized.
- Degradation is small + auditable: required-for-meaning entities never silently culled (if they can't fit → reject/retain prior); optional entities omitted in ascending priority. **Fallbacks occur ONLY through an explicitly authored `fallback_presentation_id` resolving to an in-closure record** (e.g. an image-quad falling back to an authored in-closure `material.solid.v1` quad, or a mesh to an authored in-closure `primitive.line.v1`). **The client never synthesizes a substitute** — no client-invented wireframe or replacement. Every substitution appears in both receipts + local diagnostics.

## 10. Client/backend work (GLES→Vulkan — the dominant cost, ratified)
- Replace the OpenGL ES binding with **`XR_KHR_vulkan_enable2`**; create instance/device/queues via the OpenXR path; stereo color + depth swapchains.
- Add a **transparent `XrCompositionLayerProjection`** above passthrough. Call `xrLocateViews` **only** in the native frame loop; consume poses/FOV immediately; make it impossible for transport/JNI/logging to accept them. **Spaces: app-local (world-stable, honest 3D) + view (bounded panels)** — neither asserts a physical referent, neither adds perception/export authority.
- Client-owned **precompiled SPIR-V** pipelines for solid, glyph/image, line, and restricted mesh; **no runtime compilation**. Render panels/text as geometry in the projection layer; retain the client-owned local stop/suspended shell.
- Off-frame **admission worker** + session resource store; candidate CPU IR + GPU uploads immutable; GPU ownership transferred behind fences; publish one generation handle at the frame boundary; retire old handles only after in-flight fences complete. Renderer IR = **muse's flattened draw-list after hierarchy resolution** (+ accessibility labels).
- **Split `quest_surface.cpp`** into lifecycle/composition, resource/admission, GLB-subset, and Vulkan-renderer units — **preserving the just-hardened lifecycle defenses** (stale Activity-generation/command-sequence, immediate narrowing, deliberate-resume). Java keeps bounded transport/session-lease state; native rechecks epoch/generation on every stage/commit. Bounds/display receipts remain pressure-sacrificable; **authority close is never queued behind them.**

## 11. Deferrals + seams
Ordered deltas (snapshot-only v1; `base_revision` seam), replaceable high-rate state, media streaming (MPEG-I Part 14 gate first), interaction/hit-test, A2UI controls (vocabulary inspiration only in v1 — no runtime/dependency/widget-action), `generator.sdf.v1` (negotiated render-extension seam), shader graphs/MaterialX, textures inside GLB, general glTF, skeletal/morph/particles, anchors/persistence, scene/depth/camera, hands/gaze/body/face, remote rendering, the VLM-critique authoring loop, cross-session cache, durable provenance of bodies. **None accepted as unknown fields today** — versioned seams only.

## 12. First build increment (thin end-to-end proof, not a schema island)
1. **Soma:** new **disabled** capability/provider contract + snapshot/resource/receipt validators; leave `PANEL_SNAPSHOT` untouched. Fixture emits one deterministic scene: root local entity + existing text panel + a line + a colored quad + a small hand-authored **geometry-only GLB triangle/cube**. Store golden raw bytes/digests + hostile mutations.
2. **Admission:** negotiated profile + session resource transfer/cache + the nine-stage CPU path. Host tests: wrong epoch/lease/profile/hash, stale revision, graph cycle/depth, missing resources, URI/extension rejection, overflow/NaN/index, escaping bounds, budget degradation, idempotence, cancellation, exact receipt metadata with no bodies.
3. **Vulkan backend:** render that one admitted fixture; atomic-swap only after resources/upload fences ready; submit passthrough + projection; display receipt after first successful end-frame. Exercise focus loss, lease expiry during prep, disconnect, device-loss/first-frame rollback, no auto-resume.
4. **Headset acceptance (separate device gate):** panel/text/line/quad/real-mesh appear together at intended poses; returned actual bounds/counts match independent calc; malformed/oversized never replaces prior scene; doff removes remote content; re-don inert until the existing deliberate-resume path obtains a fresh epoch/lease.
Merge order if split: protocol/admission tests → Vulkan fixed local fixture → wire the admitted fixture. **Not complete until a content-addressed GLB crosses the real Soma↔Quest boundary and renders.**

## 13. Principal risks + controls
Risks: native parser/GPU-driver attack surface; underestimated decoded/GPU cost + thermal; Vulkan migration destabilizing the just-proven lifecycle; receipt overclaiming; authority broadening hidden behind "just a renderer." Controls: narrow formats; pre-allocation caps + custom allocators; independent recomputation; off-frame cancellable preparation; precompiled pipelines; atomic generation swap/rollback; staged device tests; distinct admission-vs-display receipts; and a **new disabled capability whose old panel grants do not survive the broadened meaning.**
