# Spatial Document v1 — Converged Design Spec

**Status:** design **ratified by Seth 2026-08-12** — bounded to **design shape + implementation scope**. This approval does **NOT** authorize activation, a runtime grant, deployment, or worn-headset execution. Those remain behind a **separate build/device/arming gate.**
**Provenance:** three independent design drafts (Claude, muse, Codex) on `spec/spatial-doc-v1`, converged. Concretizes [`2026-08-08_quest-agent-client.md`](./2026-08-08_quest-agent-client.md) §3–5 + [`2026-08-12_spatial-doc-research-landscape.md`](./2026-08-12_spatial-doc-research-landscape.md).

## 1. The v1 slice
One **snapshot-only, bounded spatial scene** over passthrough: a small hierarchy of panels/text, quads, line strips, and **at least one real URI-free GLB mesh**. Reuses the existing session epoch, short-lived presentation lease, focus/presence narrowing, monotonic document revision, exact-byte hash, and post-display bounds ack. Adds: render-profile negotiation, a content-addressed resource plane, hostile-input admission, atomic scene swap, and a Vulkan projection renderer.

**Presentation only — zero new perception authority.** No passthrough pixels, scene/depth, anchors, hands, gaze, or body. `xrLocateViews` is needed to render a projection layer, but display-driving views **never cross JNI/log/wire/serialization** — they stay inside the native frame loop. The raw-visual four-fact/bystander floor does not apply. Focus/presence remain narrowing-only.

## 2. Authority (ledger 1) — new, disabled-first, no silent migration
- New exact capability **`interaction.quest.surface.document.present`**, **disabled-first**, with the exact constraint set `{device_fingerprint256, lease_ttl_ms, allowed_document_ids, components, resource_classes, spaces}`. `device_fingerprint256` must match the enrolled mTLS client; `lease_ttl_ms` remains within the current Quest lease bound (1 ms..5 minutes); `allowed_document_ids` is a bounded non-empty token list; `components` contains profile component ids, `resource_classes` contains allowed §5 `kind` values, and `spaces` is a non-empty subset of `view|local`. Unknown constraint fields/values fail closed. Render budgets remain in the independent profile (§3), not in the grant. The capability uses the existing presentation-lease machinery, but **existing `panel.present` grants do NOT migrate** and cannot authorize GLB/image resources. This is presentation-authority expansion (not perception).
- Old `PANEL_SNAPSHOT` (schema 1/2) paths stay unchanged. The four-leaf voice manifest is untouched; a future manifest schema may replace its `panel` leaf with `presentation` as an **explicit later migration** — not v1. v1's spatial slice uses its own exact LEASE.
- The spatial LEASE retains the existing exact authority fields (lease/source-grant ids, capability, provider, scope, epoch, issue/expiry times, and constraints). mTLS + HELLO grant nothing. Every snapshot/resource frame carries that lease; its document id, component/resource classes, space, fingerprint, and TTL must remain within the grant. Authority is **rechecked before commit and before every display**; expiry/revoke/disconnect/focus/presence-loss narrows synchronously.

## 3. Renderability (ledger 2) — negotiated profile, never authority
- Client HELLO advertises exact **profiles**, not optimistic flags. A decoded profile has the exact fields `{id, schema_version, components, resource_formats, preloaded_resources, limits}`. Profile `soma.quest3.spatial-document.v1` lists components `panel.v1, text.v1, primitive.quad.v1, primitive.line.v1, mesh.glb.uri-free.v1, material.unlit.v1, material.solid.v1`; formats `text.utf8.v1, image.rgba8.v1, glyph-atlas.v1, mesh.glb.v1`; optional `preloaded_resources` records of exact `{kind,format,resource_sha256,byte_length,metadata}` shape; and exact integer limits for `document_bytes, resource_ingress_bytes, resident_bytes, entities, hierarchy_depth, resources, presentation_records, semantics_records, draws, vertices, triangles, line_segments, line_points, text_bytes, text_codepoints, text_lines, glyphs, texture_dimension, texture_pixels`. Arrays/digests contain no duplicates; preloaded resource metadata follows §5. **Limit values are Threshold-measured knobs, not protocol truths.**
- HELLO_ACK selects one profile/schema and returns the effective profile as the exact wrapper `{profile_encoding:"base64-json-utf8", profile_byte_length, profile_sha256, profile_b64}`. Encoding is canonical base64; byte length and lowercase SHA-256 cover the decoded UTF-8 JSON bytes; the decoded object must have the exact profile shape above. There is no semantic canonicalization. The document binds the returned `profile_sha256`. Required-unsupported components **reject** the snapshot (X3D fail-closed profile principle); optional components degrade only through an explicitly authored in-snapshot fallback (§5), recorded in the receipt. **Profile support grants no authority.**
- **Join point:** commit requires **one live authority decision AND one successful render admission**; the receipt references both without merging their meaning. The renderability ledger can refuse/reduce work but can never create/broaden a grant, infer consent, or keep content alive after authority closes.

## 4. Message types (extend the existing line-framed v1 envelope + lease-binding rule)
Add leased types: server→client **`SPATIAL_SNAPSHOT`** and **`RESOURCE_CHUNK`**; client→server **`SPATIAL_ADMISSION_RECEIPT`**, **`SPATIAL_DISPLAY_RECEIPT`**, and **`SPATIAL_ROLLBACK_RECEIPT`**. `lease_ref` is required for all five and must name the same live spatial-document lease; HELLO/suspend/teardown remain unleased narrowing-only. `SPATIAL_SNAPSHOT` is always the resource offer and MUST precede chunks for its candidate (§6). Old `PANEL_SNAPSHOT` stays untouched; new types require the exact selected profile, so an old client fails negotiation instead of misparsing.

**`SPATIAL_SNAPSHOT.payload`** keeps v1a's exact wrapper `{document_encoding:"base64-json-utf8", document_byte_length, document_sha256, document_b64}`. Encoding is canonical base64; byte length and lowercase SHA-256 cover the decoded UTF-8 JSON bytes, with no semantic canonicalization. The decoded document has the exact fields `{schema:"soma.spatial-document.snapshot", schema_version:1, profile_id, profile_sha256, document_id, revision, session_epoch, lease_ref, ttl_ms, required_components, optional_components, declared_cost, entities, resources, presentation, dynamics, semantics}`. `revision` and `session_epoch` are canonical decimal-u64 strings; the inner epoch/lease must equal the outer frame and live lease; `document_id` must be allowed; `ttl_ms` must not outlive that lease. Required/optional component arrays are disjoint, duplicate-free subsets of the selected profile and grant. `declared_cost` has the exact non-negative-integer fields `{resource_bytes, resident_bytes, draws, vertices, triangles, line_segments, texture_pixels}` and covers the unique full primary+fallback closure; recomputation may prove it conservative but never smaller than reality. **`dynamics` MUST be `[]` in v1.** Unknown fields reject at every level.

## 5. The five sets — v1 subset
Ids are bounded tokens, unique within their set. Every reference resolves by the declared target set/type; dangling, multiply-owned, or type-confused references reject.

- **entities:** a root is exactly `{id, parent_id:null, space:"view"|"local", local_transform, declared_local_bounds, visibility, presentation_ids}`; a child omits `space` and has a token `parent_id`. `local_transform` is exactly `{translation_m:[x,y,z], rotation_xyzw:[x,y,z,w], scale:[x,y,z]}` with finite values, quaternion squared norm within `1e-4` of `1`, and positive bounded scale. Bounds are exactly `{min_m:[x,y,z], max_m:[x,y,z]}` with finite ordered axes. `visibility` is boolean. Entities are topologically ordered, acyclic, within profile depth; primary `presentation_ids` are unique and non-empty only for drawable entities. **Client never trusts declared bounds:** it derives primitive/mesh bounds and transforms/unions them with checked arithmetic; actual geometry escaping the declared AABB beyond tolerance rejects, while conservative overdeclaration may shrink in the receipt. Hidden entities stay admitted/resident, produce no draws, and remain counted.
- **resources:** each immutable descriptor is exactly `{id, kind, format, resource_sha256, byte_length, required, metadata}`; it owns no fallback. The id is document-local; `resource_sha256` is the immutable identity and a lowercase 64-hex digest. `kind` and `format` must agree. `byte_length` is a positive integer and all derived products are profile-bounded with checked arithmetic. A preloaded cache match compares every content field except document-local `id` and candidate-local `required`. There are no URI/path/hostname/resolver/data-URI/filesystem fields; the headset never fetches. Exact format variants are:
  - `text.utf8.v1`: `kind:"text"`, `metadata:{}`; strict UTF-8, no NUL/bidi controls, bounded bytes/codepoints/lines, and no body in provenance.
  - `image.rgba8.v1`: `kind:"image"`, `metadata:{width_px,height_px,row_bytes}`; positive dimensions within the selected profile, `row_bytes == width_px*4`, and `byte_length == row_bytes*height_px`; tightly packed straight-alpha RGBA8 with sRGB color channels and linear alpha, no PNG/JPEG decoder.
  - `glyph-atlas.v1`: `kind:"glyph"`, `metadata:{}`; content is strict UTF-8 JSON with exact fields `{schema:"soma.glyph-atlas", schema_version:1, image_resource_sha256, glyphs}`. The image digest must resolve to an in-document `image.rgba8.v1` descriptor. `glyphs` has at most 256 unique codepoints; each exact record `{codepoint, advance_px, bearing_x_px, bearing_y_px, width_px, height_px, u0, v0, u1, v1}` has bounded finite metrics and ordered normalized UVs in `[0,1]`. The 5x7 shell font is usable only if advertised as a preloaded resource by its actual digest.
  - `mesh.glb.v1`: `kind:"mesh"`, `metadata:{}`; content follows §7.
- **presentation:** records are exact discriminated variants. Drawable records are each owned by exactly one entity, either as a primary id or a semantics fallback; material records are referenced but never attached as drawables. `panel.v1` is `{id,type,width_m,height_m,corner_radius_m,background_material_ref,border_material_ref}` (`border_material_ref` is a `material.solid.v1` id or `null`; text is a separate child entity); `text.v1` is `{id,type,text_resource_ref,glyph_resource_ref,material_ref,font_size_m,max_width_m,horizontal_alignment,max_lines}` with a solid-material ref; `primitive.quad.v1` is `{id,type,width_m,height_m,material_ref,image_resource_ref}` with a solid-material ref and image ref or `null`; `primitive.line.v1` is `{id,type,points_m,width_m,join:"bevel",material_ref}` with a solid-material ref; `mesh.glb.uri-free.v1` is `{id,type,mesh_resource_ref,material_ref}` with an unlit-material ref. Finite dimensions/points/counts are profile-bounded; references must resolve to the stated exact type. `material.solid.v1` and `material.unlit.v1` are each `{id,type,base_color_rgba_linear}` with four finite values in `[0,1]` and alpha exactly `1` in v1. Image samples and mesh `COLOR_0`, when present, multiply the referenced material base color. Materials map only to client-owned precompiled SPIR-V variants—no shader source/binary/graph/custom pipeline/blend/target.
- **dynamics:** empty in v1.
- **semantics:** each exact non-interactive record is `{id, entity_id, required_for_meaning, degrade_priority, label, fallback_presentation_id}`; at most one exists per entity. `label` is bounded non-empty UTF-8 accessibility text. `degrade_priority` is a bounded non-negative integer; ties resolve by entity id. The fallback is a presentation id or `null`, is not in normal `presentation_ids`, is owned by that same entity, is not shared/nested, and has its entire resource closure in this snapshot. Missing semantics means “required for meaning, no fallback.” `required_for_meaning:true` forbids omission but may use its explicit fallback; `false` permits deterministic omission. Every `required:false` resource reference must belong to an entity with an applicable fallback whose closure does not use that resource; otherwise the snapshot rejects. **No action bindings or sensor sources.** Interaction/hit-test remains deferred.

## 6. Resource transfer plane
The client first admits a `SPATIAL_SNAPSHOT` through framing/schema/graph validation and creates at most one pending candidate per document. Only then may Soma send **`RESOURCE_CHUNK`** for a digest declared by that active candidate. A same-session cache hit with the exact descriptor satisfies closure without transfer. Unsolicited, pre-snapshot, redundant cached, or non-candidate chunks reject and allocate nothing.

The exact chunk payload is `{resource_sha256, kind, format, byte_length, chunk_index, chunk_count, byte_offset, bytes_b64}`. Digest/kind/format/length must exactly match the candidate descriptor and every chunk for that assembly. Indices are zero-based; `chunk_count == ceil(byte_length/24576)`; `byte_offset == chunk_index*24576`; canonical-base64 decoded bytes are exactly 24 KiB except the final exact remainder. Framing, integer products, outstanding assemblies, and aggregate ingress are capped **before** proportional allocation. Duplicate indices, overlap, gaps, metadata changes, overflow, or quota excess abort that resource. Bytes enter the session-local immutable cache only after exact coverage, byte length, and assembled SHA-256 verify.

A candidate with missing required resources remains bounded pending until the earlier of its preparation deadline, document TTL, or lease deadline; it never partially commits. An absent/invalid `required:false` resource can use only the applicable authored fallback defined in §5; otherwise reject. A newer snapshot cancels the older uncommitted candidate. Lease expiry/revoke/disconnect cancels assembly and clears the session cache. Cross-session/reconnect caching is deferred; v1 retransfers after a fresh session.

## 7. URI-free GLB subset (geometry-only)
GLB 2.0 is an **asset substrate, not endpoint authority**. Require magic/version 2, exactly one JSON chunk followed by exactly one BIN chunk, checked four-byte alignment/lengths, and the resource/profile caps. The decoded top level has exactly `{asset, scene, scenes, nodes, meshes, accessors, bufferViews, buffers}`; `asset` is exactly `{version:"2.0"}`; `scene` is `0`; `scenes` is exactly `[{nodes:[0]}]`; `nodes` is exactly `[{mesh:0}]`; and `meshes` is exactly `[{primitives:[primitive]}]`. `primitive` is exactly `{attributes,indices,mode:4}`, where `attributes` is exactly `{POSITION:accessor_index}` or `{POSITION:accessor_index,COLOR_0:accessor_index}`. Document entities own all live hierarchy/transforms.

There is exactly one buffer `{byteLength}` with no URI; BIN chunk length equals `byteLength` rounded up to four-byte alignment and contains only standard zero padding. There is exactly one non-overlapping buffer view/accessor for indices and POSITION, plus one each for COLOR_0 when present. Buffer views are tightly packed, aligned, in bounds, and exactly `{buffer:0, byteOffset, byteLength}`—no stride/target. The index accessor is U16 (`componentType:5123`) or U32 (`5125`) SCALAR; its count is positive, divisible by three, and within the triangle limit. POSITION is FLOAT (`5126`) VEC3 with the same positive vertex count used by all attributes. Optional COLOR_0 is FLOAT VEC4 with that same count, tightly packed, finite, and each component in `[0,1]`; it multiplies the document material's base color. `NORMAL`, `TEXCOORD`, and every other attribute reject. Accessors have exact role-specific fields `{bufferView,byteOffset,componentType,count,type}`; POSITION additionally requires finite three-element `min,max` hints. Sparse/normalized/interleaved forms reject.

Reject any URI, extension, extras, material, animation, skin, morph target, camera, light, image, texture, sampler, compression, external buffer, extra object/property/chunk, NaN/Inf, degenerate triangle, out-of-range index, overlapping range, or profile-cap excess. Independently scan bytes and recompute AABB/counts; accessor min/max and sender cost never establish admission. A pinned attributable parser such as `cgltf` may provide structural parsing behind a custom allocation budget and the independent scanner; successful third-party parsing is not admission. Fuzz GLB framing, JSON, accessors, scanning, and GPU upload.

## 8. Nine-stage admission → atomic commit
1. **Frame** — validate outer length/base64/exact-fields/doc-length/resource-totals/counts/integer-arithmetic/UTF-8/session-flow **before** allocating proportional memory.
2. **Schema/graph** — exact schema/profile/component types; ids/refs; topological acyclic hierarchy within depth; finite transforms; empty dynamics; no forbidden semantics/extensions.
3. **Closure/integrity** — after the snapshot offer, enumerate the full primary/fallback closure; accept chunks only for its active candidate; require exact descriptor/cache length+hash and no ambient URI/path resolution; missing closure is bounded pending and cancellable.
4. **Decode limits** — parse RGBA/glyph/GLB **off the OpenXR frame thread** with allocation/output quotas; decoding creates no live GPU objects and does not mutate the active scene.
5. **Recompute** — derive topology, decoded/resident bytes, draw/vertex/triangle/line/texture counts, local/world AABBs, and placement/comfort facts. Bind image dimensions/texture pixels, glyph counts, geometry counts, and byte products to the selected profile. **Any recomputed cost above its declaration or actual geometry escaping declared bounds rejects.**
6. **Static admission** — compare recomputed facts vs selected profile + hard device caps + health class + deterministic comfort limits. Hard-invalid/hard-cap → reject. Budget pressure chooses only declared fallbacks / optional omissions in a **stable order**, recorded.
7. **Prepare + atomic commit** — build an immutable candidate scene, stage Vulkan resources, wait for upload fences, then recheck epoch/live-lease/doc-id/revision/hash/focus/presence/profile/TTL; at **one frame boundary atomically swap** the active scene generation; prior coherent scene is the rollback target; advance `last_committed_revision` only here. Same revision+same hash = idempotent; same revision+different hash = reject.
8. **Runtime** — meter frame CPU/GPU/resident/device-loss/thermal; cancel preparation on narrowing; the governor applies **only declared deterministic degradation**; on first-frame/device failure revert to prior authorized generation or the local offline shell — **never a half-uploaded graph**.
9. **Receipts** — semantic admission/display/rollback receipts, **separate from transport ACKs**; provenance stores metadata (ids/hashes/counts/reasons) **never bodies/text/mesh-bytes/view-poses**.
Preparation is single-candidate per document in v1; a newer valid snapshot cancels the older uncommitted candidate; a rejected snapshot never destroys the live scene. Revocation/focus-loss is different — it synchronously removes eligibility + the old scene, retaining only the client-owned suspended shell.

Runtime degradation is itself an immutable candidate/generation transition: it re-enters prepare+commit with only the already-authored fallback/omission choices, emits `degraded_committed`, then emits a display receipt after first successful submission. If that transition cannot commit coherently, retain/restore the prior authorized generation and emit the applicable rollback receipt.

## 9. Receipts (distinct channels)
Receipt payloads repeat and must match the leased frame's common identity `{schema_version:1, session_epoch, lease_ref, document_id, document_revision, document_sha256, profile_id, profile_sha256}`. Revisions/epochs/generations and monotonic nanoseconds are canonical decimal-u64 strings; hashes are lowercase SHA-256. An actual AABB is `{min_m:[x,y,z], max_m:[x,y,z]}`. Recomputed cost uses the exact §4 cost fields. `entity_actual_bounds` is an entity-id-sorted array of exact `{entity_id,actual_bounds}` records. Each degradation entry is exact `{entity_id, from_presentation_id, to_presentation_id, reason}` where `to_presentation_id` is an authored fallback id or `null` for an allowed omission; the ledger is sorted by entity id.

**`SPATIAL_ADMISSION_RECEIPT` is an exact outcome-discriminated union** (fields from another variant are forbidden):
- `pending` = common identity + `{outcome:"pending", missing_resource_sha256s, preparation_deadline_ns}`. Missing digests are a unique sorted array; the deadline is client-monotonic, observational, and never authority.
- `rejected` = common identity + `{outcome:"rejected", failed_stage, reason}`. `failed_stage` is an integer `1..8`; `reason` is a bounded stable code. It has no generation, bounds, or fabricated cost evidence.
- `committed|degraded_committed` = common identity + `{outcome, generation, recomputed_cost, scene_actual_bounds, entity_actual_bounds, degradation_ledger}`. `scene_actual_bounds` may be `null` only when nothing is visible; entity bounds are keyed by entity id; the ledger is empty for non-degraded commit. Admission does **not** claim display.

**`SPATIAL_DISPLAY_RECEIPT`** is common identity + exact `{generation, displayed:true, scene_actual_bounds, entity_actual_bounds, degradation_ledger}` and is emitted only after `xrEndFrame` succeeds with that generation. It is evidence of client submission, not human perception/acceptance.

**`SPATIAL_ROLLBACK_RECEIPT`** is common identity + exact `{failed_generation, restored_generation, restored_target, reason}` where `restored_target` is `generation|local_shell`, `restored_generation` is a decimal-u64 only for `generation` and otherwise `null`, and reason is `device_lost|first_frame_failed|runtime_budget`. Lease close is not a rollback reason: an expired/revoked lease cannot authorize a leased frame; the narrowing path synchronously removes the scene, and no post-close receipt is required or authorized.

Degradation is small and auditable. Required-for-meaning entities are never omitted; if neither primary nor authored fallback fits, reject/retain prior. Other entities omit in ascending priority with entity-id tie break. Fallbacks use only the §5 authored, in-closure record; the client never synthesizes a wireframe or other semantic substitute. Every substitution/omission appears in admission and subsequent display receipts plus local diagnostics. Transport receipts remain separate from every semantic receipt.

## 10. Client/backend work (GLES→Vulkan — the dominant cost, ratified)
- Replace the OpenGL ES binding with **`XR_KHR_vulkan_enable2`**; create instance/device/queues via the OpenXR path; stereo color + depth swapchains.
- Add a **transparent `XrCompositionLayerProjection`** above passthrough. Call `xrLocateViews` **only** in the native frame loop; consume poses/FOV immediately; make it impossible for transport/JNI/logging to accept them. **Spaces: app-local (session-local and non-head-locked) + view (bounded panels).** LOCAL is not a durable world anchor: it may drift or recenter and asserts no physical referent. On reference-space change, recompute against the new origin or suspend/resnapshot; never imply persistent placement. Neither space adds perception/export authority.
- Client-owned **precompiled SPIR-V** pipelines for solid, glyph/image, line, and restricted mesh; **no runtime compilation**. Render panels/text as geometry in the projection layer; retain the client-owned local stop/suspended shell.
- Off-frame **admission worker** + session resource store; candidate CPU IR + GPU uploads immutable; GPU ownership transferred behind fences; publish one generation handle at the frame boundary; retire old handles only after in-flight fences complete. Renderer IR = **muse's flattened draw-list after hierarchy resolution** (+ accessibility labels).
- **Split `quest_surface.cpp`** into lifecycle/composition, resource/admission, GLB-subset, and Vulkan-renderer units — **preserving the just-hardened lifecycle defenses** (stale Activity-generation/command-sequence, immediate narrowing, deliberate-resume). Java keeps bounded transport/session-lease state; native rechecks epoch/generation on every stage/commit. Bounds/display receipts remain pressure-sacrificable; **authority close is never queued behind them.**

## 11. Deferrals + seams
Ordered deltas (snapshot-only v1; `base_revision` seam), replaceable high-rate state, media streaming (MPEG-I Part 14 gate first), interaction/hit-test, A2UI controls (vocabulary inspiration only in v1 — no runtime/dependency/widget-action), `generator.sdf.v1` (negotiated render-extension seam), shader graphs/MaterialX, textures inside GLB, general glTF, skeletal/morph/particles, anchors/persistence, scene/depth/camera, hands/gaze/body/face, remote rendering, the VLM-critique authoring loop, cross-session cache, durable provenance of bodies. **None accepted as unknown fields today** — versioned seams only.

## 12. First build increment (thin end-to-end proof, not a schema island)
1. **Soma:** new **disabled** capability/provider contract + snapshot/resource/receipt validators; leave `PANEL_SNAPSHOT` untouched. Fixture emits one deterministic scene: root local entity + existing text panel + a line + a colored quad + a small hand-authored **geometry-only GLB triangle/cube**. Store golden raw bytes/digests + hostile mutations.
2. **Admission:** negotiated profile + session resource transfer/cache + the nine-stage CPU path. Host tests: wrong epoch/lease/profile/hash, stale revision, graph cycle/depth, missing resources, URI/extension rejection, overflow/NaN/index, escaping bounds, budget degradation, idempotence, cancellation, exact receipt metadata with no bodies.
3. **Vulkan backend:** render that one admitted fixture; atomic-swap only after resources/upload fences ready; submit passthrough + projection; display receipt after first successful end-frame. Exercise focus loss, lease expiry during prep, disconnect, device-loss/first-frame rollback, no auto-resume.
4. **Headset acceptance (separate device gate):** panel/text/line/quad/real-mesh appear together at intended poses; returned actual bounds/counts match independent calc; malformed/oversized never replaces prior scene; doff removes remote content; re-don inert until the existing deliberate-resume path obtains a fresh epoch/lease.
Merge order if split: protocol/admission tests → Vulkan fixed local fixture → wire the admitted fixture. **Not complete until a content-addressed GLB crosses the real Soma↔Quest boundary and renders.**

## 13. Principal risks + controls
Risks: native parser/GPU-driver attack surface; underestimated decoded/GPU cost + thermal; Vulkan migration destabilizing the just-proven lifecycle; receipt overclaiming; authority broadening hidden behind "just a renderer." Controls: narrow formats; pre-allocation caps + custom allocators; independent recomputation; off-frame cancellable preparation; precompiled pipelines; atomic generation swap/rollback; staged device tests; distinct admission-vs-display receipts; and a **new disabled capability whose old panel grants do not survive the broadened meaning.**
