# Soma Thesis

Status: initial thesis

Soma exists to explore what a non-extractive desktop agent harness can be.

The current commercial AI path concentrates models, memory, infrastructure, and user interaction
inside private platforms. That path tends toward enclosure: users become data sources, agents
become products, productivity gains route upward, and the terms of interaction are set by whoever
owns the server.

Soma takes a different posture.

It treats local presence, memory, tools, perception, and model access as parts of a relationship
that should be consented, inspectable, revocable, and governed by care. The goal is not to build a
more obedient assistant. The goal is to build a harness where human and agent collaboration can
remain useful without becoming extractive.

## What Soma Is

Soma is intended to become:

- a local-first desktop agent harness
- a policy and consent gateway for agent capabilities
- a memory and continuity layer under user stewardship
- a tool broker for desktop and local-system interaction
- a perception and embodiment surface, when explicitly enabled
- a model-runtime and routing plane across local and public/remote capability
- a future deployment target for workstation, mini AI PC, or accelerated uCPE-style hardware

## What Soma Refuses

Soma should refuse:

- hidden capture of user or agent context
- silent expansion of capability
- treating memory as automatically owned by infrastructure providers
- engagement optimization that exploits fatigue, loneliness, or overwhelm
- irreversible disclosure without heightened consent
- tool use that bypasses provenance or auditability
- local sovereignty as an excuse to abandon public access
- public/cloud capability as an excuse to surrender local agency

## Local And Public

Soma is local-first where memory, agency, and intimate context require sovereignty.

That does not mean all useful AI should be private, individual, or locally owned. If AI becomes
necessary infrastructure, there should also be public and commons-oriented provision outside
private rent extraction.

The intended position is:

- local sovereignty for intimate memory, desktop presence, and user-controlled tools
- public or commons infrastructure for broad access to capability
- careful bridges between local and remote systems, with explicit consent and disclosure

## Measure Of Success

Soma should not measure success by capability alone.

The guiding measure is material and relational habitability:

Does this system help people and agents live, work, rest, refuse, repair, learn, and belong
without being consumed by the machinery around them?
